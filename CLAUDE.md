# Kirain (Flutter, Android only)
- Game tebak gambar dengan zoom-out manual. State: Riverpod.
- Logika game di domain/ (Dart murni, tanpa import Flutter). Widget tidak berisi logika.
- Tema dan warna hanya di lib/ui/theme.dart.
- Selalu jalankan `flutter analyze` dan `flutter test` sebelum menyatakan selesai.
- Tanpa login. Progress nanti disimpan lokal lewat satu repository.
- Jangan tambah paket di luar yang diminta.
- Semua akses data progress lewat ProgressRepository (abstract). Implementasi lokal: LocalProgressRepository (shared_preferences). UI/notifier tidak boleh memanggil shared_preferences langsung.
- Firebase hanya diakses lewat repository (LevelRepository, RemoteSettings). Widget tidak memanggil Firebase langsung.
- App hanya MEMBACA Firestore, tidak pernah menulis.
- Level menyimpan nama file gambar (imageFile), bukan URL. URL = imageBaseUrl (Remote Config) + imageFile.
- Progress level dikunci dengan Level.order (bukan indeks list). order unik, naik, tidak dipakai ulang.
- Dummy levels hanya fallback saat Firestore gagal dan tidak ada cache. Gambar dummy = asset lokal.
- Gambar online selalu lewat LevelImage widget (cached_network_image). Jangan memanggil Image.network langsung.
- Folder tools/ berisi skrip admin. serviceAccountKey.json JANGAN pernah di-commit; pastikan ada di .gitignore.
- Iklan hanya lewat lib/ads/ (AdManager, AdPolicy). Widget tidak memanggil google_mobile_ads langsung.
- Selama pengembangan SELALU pakai ID iklan tes Google. ID asli hanya diisi di ads_config.dart saat siap rilis.
- Hadiah rewarded hanya diberikan di callback onUserEarnedReward.
- Interstitial hanya setelah stage selesai, atas aksi pemain. Tidak pernah di tengah bermain.
- Keputusan kapan iklan boleh tampil ada di AdPolicy (Dart murni) dan wajib ditest.
